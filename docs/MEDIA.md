# Как сделаны изображения и видео

Материалы в `docs/media` показывают вымышленный рабочий стол. Это не запись
личного компьютера разработчика и не фотография его окон.

Сцена создаётся в `src/DemoScene.cs`: фон, условный Проводник, заметки, папки и
панель задач рисуются из заранее заданных фигур и строк. Снег, гирлянда,
экскаватор, ёлочка, снеговик и таймер рисует настоящий `WinterRenderer`.
Для анимации используется настоящий `SnowWorld`, включая уборку ковшом,
вихрь и смахивание снега варежкой.

- Источник случайных чисел фиксирован: `24122026`.
- Демонстрационная дата фиксирована: 24 декабря 2026 года, 19:30.
- `screenshot.png` — кадр этой сцены на третьей секунде.
- `settings.png` — окно настроек, нарисованное приложением вне экрана через `DrawToBitmap`.
- `demo.mp4` — 14 секунд, 1920×1080, 30 fps; подписи добавлены в HyperFrames.
- `demo.gif` — уменьшенная анимированная версия того же ролика для README.

Экспорт не использует захват экрана, реальные заголовки окон, пользовательские
файлы, микрофон или сетевые изображения. Во время экспорта реальный Windows
overlay не запускается, реальные окна не перечисляются.

Воспроизвести исходную сцену после сборки (нужен FFmpeg с libx264):

```powershell
Start-Process .\dist\QuietWinter.exe -ArgumentList '--export-demo', "$PWD\artifacts\demo", '--ffmpeg', 'ffmpeg.exe' -Wait
Start-Process .\dist\QuietWinter.exe -ArgumentList '--render-settings', "$PWD\artifacts\settings.png" -Wait
```

`media-project/index.html` описывает оформление ролика. Для воспроизведения
этой композиции поместите исходный MP4 в `media-project/assets/native-demo.mp4`
и файл `seguisb.ttf` из установленной Windows в `media-project/assets/fonts/`.
Шрифт Windows не распространяется в репозитории. Приложению и готовым роликам
эти инструменты и файлы не нужны.
